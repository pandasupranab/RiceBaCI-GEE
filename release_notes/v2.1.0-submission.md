# Release v2.1.0-submission

**Date:** 13 June 2026
**Tag:** `v2.1.0-submission`
**Status:** Submission package for *Remote Sensing of Environment* (first submission).

This release captures the version of the code, data, and manuscript actually submitted to RSE. It extends `v1.0.2-frozen` with additional identification and robustness analyses included in the submitted version.

## What changed since v1.0.2

The submitted version includes **five additional identification and robustness analyses** beyond the v1.0.2 baseline, all reproducible from this repo:

## Reproducibility

To regenerate the v2.1 submission deliverables from a fresh clone:

```bash
# Reproduce extended robustness analyses
python analysis/reviewer_rebuttal_analysis.py
python analysis/module_14_pretrend_placebo.py
python analysis/module_15_balanced_pixel_did.py

# Rebuild all v22 figures
cd figures/v22 && for s in build_fig*.py; do python $s; done

# Rebuild manuscript and supplement DOCX/PDF
cd manuscript/v2/source && python build_docx_pdf.py
```

The v22 GEE exports require Google Earth Engine credentials; run `gee/v22/*.js` in the GEE Code Editor and download the resulting CSVs to `analysis/v22/`.
