## Data Availability Statement

All data and code necessary to reproduce the analysis are publicly available:

- **Primary panel data** (baci_panel_real_v22.csv and derived analysis files): GitHub repository https://github.com/pandasupranab/RiceBaCI-GEE, branch v2.0-refit, tag v2.0-rse.
- **Zenodo archive** (code and panel, v2.0 snapshot): DOI 10.5281/zenodo.20587316.
- **Mendeley Data deposit** (pixel-level uncertainty rasters and label set): DOI 10.17632/z3zxk4xy3c.1.
- **OSF pre-registration**: DOI 10.17605/OSF.IO/C4MP8. The pre-registration documents all hypotheses, the DiD estimating equation, and the QC gate definitions prior to data analysis.
- **Google Earth Engine cloud project**: durable-pulsar-486209-b5 (GEE JavaScript source code is version-controlled in the GitHub repository above).
- **Satellite data sources**: All Sentinel-2 L2A data are publicly accessible via the Copernicus Open Access Hub (https://scihub.copernicus.eu) or the Google Earth Engine Data Catalog (collection: `COPERNICUS/S2_SR_HARMONIZED`). ESA WorldCover v200 is available at https://worldcover2021.esa.int. IBTrACS v04r00 is available at https://www.ncei.noaa.gov/products/international-best-track-archive. ERA5-Land is available via the ECMWF Climate Data Store (https://cds.climate.copernicus.eu).
