# RSE Submission Checklist

A field-by-field walkthrough of the Elsevier Editorial Manager submission for *Remote Sensing of Environment*.
URL: <https://www.editorialmanager.com/RSE/>

---

## Pre-flight (do these BEFORE you log in)

- [ ] All co-authors confirmed, with full names, ORCIDs, affiliations, and emails
- [ ] Corresponding author identified and reachable
- [ ] Cover letter PDF ready (`00_cover_letter.md` rendered to PDF)
- [ ] Manuscript Word file finalised in single-column layout
- [ ] All figures saved as separate files at ≥ 300 DPI, named `Figure_1.tiff`, `Figure_2.tiff`, …
- [ ] Highlights `.docx` ready (file name must contain "highlights")
- [ ] Graphical abstract image at 531 × 1328 px (or proportionally larger), readable at 5 × 13 cm
- [ ] Tables included in the manuscript text as editable text (not images)
- [ ] All references have DOI URLs and are formatted in Elsevier (Harvard) style
- [ ] CRediT author statement in the manuscript
- [ ] Declaration of Generative AI Use in the manuscript
- [ ] Funding statement in the manuscript
- [ ] Data Availability Statement in the manuscript
- [ ] Acknowledgements section
- [ ] Mendeley Data DOI minted (reserve a DOI before submission; deposit on acceptance)
- [ ] OSF pre-registration URL confirmed live and public
- [ ] GitHub repository public and citation-ready (`CITATION.cff` present)
- [ ] Word count ≤ 15,000 (Original Research) including references and figure captions
- [ ] Abstract ≤ 250 words
- [ ] Highlights: exactly 3–5 bullets, each ≤ 85 characters
- [ ] No line numbering in the manuscript
- [ ] No PDF as the source file — submit Word `.docx`

## Editorial Manager — step-by-step

### Step 1 — Article Type
- Select: **Original Research Article**

### Step 2 — Title and Abstract
- Title: Decoupling Cyclone-Induced Saline Inundation from Agronomic Flooding in Sentinel-1/2 Rice Phenology Retrieval: A Multi-Year Bay-of-Bengal Coastal Framework (2017–2024)
- Abstract: paste from manuscript (≤ 250 words)

### Step 3 — Keywords
- 6 keywords (no "and"/"of"). Suggested:
  1. Sentinel-1
  2. Sentinel-2
  3. rice phenology
  4. tropical cyclone
  5. SAR-optical fusion
  6. BACI design

### Step 4 — Authors
- Add all authors in submission order
- Mark corresponding author
- Provide ORCID for each
- Affiliations with full postal address and country

### Step 5 — Suggest / Oppose Reviewers
- Suggest 3–5 reviewers (see cover letter)
- Optionally oppose specific individuals (use sparingly)

### Step 6 — Additional Information
- Funding source: see Funding Declaration
- Conflicts of interest: none
- Generative AI use: yes — see declaration in manuscript
- Preprint: optional. SSRN posting via the submission flow gets you a DOI immediately.
- Open access choice: the journal is hybrid; decide between subscription (no fee) and gold OA (~ USD 4,200).

### Step 7 — File Upload
Upload in this order, each as a separate file:

1. `Cover_Letter.pdf`
2. `Manuscript.docx` — main file, single-column
3. `Highlights.docx` — must include "highlights" in the filename
4. `Graphical_Abstract.tiff`
5. `Figure_1.tiff` … `Figure_10.tiff`
6. `Table_1.docx` … `Table_3.docx` (or include in manuscript text)
7. `Supplementary_Material.pdf` (if any)

### Step 8 — Review and Approve
- Generate the system PDF (combined for reviewers)
- Verify: figures render, tables format correctly, no broken DOI links
- Approve and submit
- Save the submission ID number

## Post-submission

- [ ] Save the submission confirmation email
- [ ] Mendeley Data deposit completed; DOI matches manuscript
- [ ] Update OSF page with "submitted to RSE on [date]"
- [ ] Tag the GitHub release as `v1.0-submission`
- [ ] If posting on SSRN: download the SSRN preprint DOI and add to your CV
- [ ] Set a reminder for 6 weeks: if no decision, polite query to the editorial office
- [ ] Set a reminder for 12 weeks: escalate if no decision

---

## After first decision

| Decision | What to do |
|---|---|
| Accept (rare on first round) | Celebrate, then complete proofs and copyright forms |
| Minor revision | 4-week response window typical; address every reviewer point in a point-by-point response letter |
| Major revision | 8-week window typical; rerun analyses if requested; track changes in manuscript |
| Reject and resubmit | Treated as a new submission; address concerns and resubmit with cover letter referencing the previous round |
| Reject without resubmission option | Use the Article Transfer Service to **JAG** (Int'l J. Applied Earth Observation and Geoinformation), which keeps reviewer history |
| Desk-reject | Move directly to JAG via Article Transfer; no time lost |
